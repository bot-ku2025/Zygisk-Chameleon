# Zygisk Chameleon

Adaptive per-app root cloaking, ephemeral namespace isolation, and synchronized kernel identity spoofing with native WebUI for KernelSU, APatch, and Magisk.

## Features
- **Adaptive Cloaking**: Per-app detection evasion tailored for banking apps, enterprise MDM, and Play Integrity checks.
- **Kernel & Zygote Cloak**: Dynamic mount isolation, `/proc` and `/sys` state sanitization.
- **Synchronized Identity Spoofing**: Real-time property and fingerprint synchronization.
- **Native WebUI**: Intuitive responsive interface for real-time monitoring and configuration on KernelSU and APatch.
- **Zero-Server OTA Updates**: Automated updates directly through GitHub releases using standard `update.json`.

## Installation
1. Download the latest `zygisk-chameleon-*.zip` from the **Releases** tab.
2. Flash the zip in **KernelSU**, **APatch**, or **Magisk**.
3. Reboot your device.
4. Open the WebUI via KernelSU/APatch app manager to configure profiles.
